# About pret

pret[^1] is a collective of passionate fans attempting to reverse-engineer and contributing to the technical documentation of our favorite video games towards a better understanding of how various aspects of their engines were implemented. Each project is autonomous and one or more projects may share the maintainer or group of maintainers.

You can reach out to us mainly through the Discord [pret](https://discord.gg/d5dubZ3) server[^2], but we also have IRC presence at [libera#pret](https://web.libera.chat/?#pret).

[^1]: Officially, the name "pret" does not have any meaning, has never been an acronym, and is always spelled in lowercase. When it became necessary to choose an umbrella term for the original IRC channel (called `#skeetendo` up to circa 2014), the Dutch and Afrikaans [*pret*](https://en.wiktionary.org/wiki/pret) or the French [*prêt*](https://en.wiktionary.org/wiki/prêt) and the name of the aforementioned Pokémon GB/GBC reverse engineering tools repository served as sources of inspiration for catchy alternatives to more goal-oriented proposals such as `#pokedisasm` and `#pokeasm`. This predates the centralization of that repository along with pokered and pokecrystal in a Git forge and the subsequent GitHub organization later adopted the same name [as of October 3, 2015](https://protocrystal.neocities.org/timeline#2015-10-03).

[^2]: You may come across an invite link for the old server, which is abandoned and no longer actively monitored.
